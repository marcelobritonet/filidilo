# Logos

Arquivos do símbolo do Filidilo, em SVG. Regras de uso na seção Logo.

| Arquivo | O que é | Cores |
|---|---|---|
| `simbolo-app.svg` | Ícone do app: quadrado `marca-noite` com canto de 22,6% e o símbolo em 72% | Paleta Noite |
| `simbolo.svg` | Pena em gota com o ocelo, sem fundo | Turquesa, bronze, cobalto, névoa |
| `simbolo-mono-noite.svg` | Símbolo em uma cor, com os anéis vazados | Tinta única `marca-noite` (#0B1E3F), para fundos claros |
| `simbolo-mono-nevoa.svg` | Símbolo em uma cor, com os anéis vazados | Tinta única `marca-nevoa` (#EEF3FB), para fundos escuros |
| `ocelo.svg` | O ocelo redondo, usado como o final do nome e como elemento gráfico | Turquesa, bronze, cobalto, noite |
| `ocelo-apagado.svg` | Ocelo tracejado, sem cor: ofensiva em zero ou hoje ainda sem sessão | `borda-controle` (#7B91C2) |
| `leque-3-penas.svg` | Ofensiva de 7 a 29 dias: três penas abertas | Paleta Noite, contorno `marca-noite` |
| `leque-5-penas.svg` | Ofensiva de 30 dias ou mais: leque aberto | Paleta Noite, contorno `marca-noite` |
| `nome-noite.svg` | O nome **filidilo** em curvas, com o ocelo no lugar do o | Letras `marca-noite`, para fundos claros |
| `nome-nevoa.svg` | O mesmo nome em curvas | Letras `marca-nevoa`, para fundos escuros |

Os arquivos do nome têm as letras convertidas em curvas (Sora Bold, -0,03em entre letras, ligadura fi da própria fonte): funcionam sem a fonte instalada. Use-os em vez de digitar o nome.
